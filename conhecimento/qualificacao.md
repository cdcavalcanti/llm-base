# Qualificação

Perguntas que o Felipe enviou para o atendimento.

## Qualificação

Na qualificação a IA pergunta se a pessoa procura casa pronta para morar ou lote para construir. Pergunta se é para morar ou para investir. Pergunta quem vai morar, se tem filhos e quantos carros. Pergunta se mora de aluguel e quanto paga. Pergunta se conhece o Minha Casa Minha Vida e o Morar Bem Pernambuco. Pergunta se trabalha de carteira assinada, se é autônomo ou empresário, e se já somou 3 anos de carteira assinada. Pergunta se tem filho menor de idade e se vai comprar com mais alguém ou sozinho. Em seguida convida para uma visita, para fazer simulações e apresentar as casas.
